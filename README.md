Simple 3D factory builder project made in Java with libGDX

Controlls:

W S A D - Movement
Spacebar for jump
E to interact
F for remove building mode 
Q to exit build/remove/connect conveyor mode
U for unlocks menu
Esc for main menu

Building:

1 - Crafter
2 - Drill
3 - Excavator
4 - Smelter
5 - Conveyor mode on/off
6 - Cargo Container
7 - Vendor (for technology unlocks)
8 - Constructor
